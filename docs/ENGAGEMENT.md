# Research and commercial evaluation

Research and commercial inquiries are open at
[teslable.research@gmail.com](mailto:teslable.research@gmail.com).

## Purpose of the current preview

The project is validating which form of the private corpus is genuinely useful
to researchers and technical organizations.

No public raw release or immediate self-service purchase is offered. The goal
is to learn which technical problem, evidence depth, and delivery format create
real value.

## Evaluation tracks

### 1. Ten-case Deep Evidence Pilot

A selected multi-layer set designed for close technical review.

Useful questions include:

- Is ten cases enough for an initial evaluation?
- Which evidence layers are mandatory?
- Is heterogeneous depth useful or should a subset meet a fixed coverage gate?

### 2. Parser and Decoder Validation Pack

A focused regression asset containing selected raw evidence, edge cases,
negative cases, fixtures, and expected results.

Useful questions include:

- Which source formats should be supported?
- Is the need for raw evidence, normalized events, expected decoder output, or
  all three?
- Which failure modes matter most to the target tool?

### 3. Anomaly Evidence Dossier

A narrow research package around one reproducible observation, including
supporting evidence, counterexamples, methodology, and explicit unknowns.

Useful questions include:

- Is the buyer evaluating a parser, protocol implementation, security claim, or
  product behavior?
- What level of independent reproduction is required?

### 4. Private Corpus Query

A partner supplies a precise question. The question is tested against the
private corpus, and the result is delivered with agreed supporting evidence.

This model can answer a corpus-wide question without transferring the full
library.

### 5. Custom integration

The internal tools or workflow are adapted to a partner's data, formats,
regression environment, or research objective.

## Information requested from interested researchers

Please describe:

1. the technical problem you need to solve;
2. the essential evidence layers;
3. the number and depth of cases that would be useful;
4. required original and derived file formats;
5. whether you need raw evidence, expected outputs, a report, a query result, or
   a tool integration;
6. the validation or procurement process inside your organization;
7. whether the work is for internal research, tool development, regression,
   publication, or another use.

Pricing has not been fixed because scope, evidence depth, rights, and technical
support materially change the product. Evaluation and future enterprise
licensing are handled by inquiry.
